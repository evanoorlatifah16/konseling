Privasi: audio dikirim ke Google (Gemini API). Pakai API key dari proyek dengan billing aktif, karena sepengetahuan saya tier gratis dapat dipakai Google untuk meningkatkan produknya; cek ketentuan terbaru. Rekam hanya dengan persetujuan, dan gunakan kode klien, bukan nama.
Klien di bawah umur. Pastikan ada persetujuan orang tua/wali untuk merekam, dan ikuti kebijakan sekolah tentang kerahasiaan konseling.
⚙️ Pengaturan API
Key hanya tersimpan di browser perangkat ini. Jangan membagikan file ini setelah key tersimpan.
📘 Cara mendapatkan API key
  1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
  2. Klik Create API key, lalu pilih proyek yang ada atau buat proyek baru.
  3. Salin key yang muncul (diawali AIza) dan tempel di kolom di atas.
  4. Aktifkan billing pada proyek tersebut (lewat Google Cloud Console atau tautan upgrade di AI Studio), agar data tidak dipakai untuk peningkatan produk Google. Tes koneksi tidak bisa memastikan hal ini, jadi cek statusnya di AI Studio.
  5. Tekan Tes koneksi. Jika muncul tanda ✅, aplikasi siap dipakai.
Tampilan Google bisa berubah sewaktu-waktu. Perlakukan key seperti kata sandi: jangan dibagikan atau dikirim lewat chat.

🛟Cadangan
Riwayat tersimpan terenkripsi (AES-256) hanya di browser perangkat ini, tidak di server mana pun. Menghapus data browser, ganti perangkat, atau lupa kata sandi akan menghilangkan riwayat.
